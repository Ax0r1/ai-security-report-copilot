# Security Policy

## Supported versions

Only the latest release on the default branch is currently supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues. Open a private security advisory when available, or contact the maintainers privately through the repository owner profile with the subject `SentinelMesh security report`.

Include a clear description, affected version or commit, reproduction steps using only authorized systems, and a suggested mitigation when possible. Do not include live API keys, personal data, or information obtained from systems without permission.

We will acknowledge valid reports as soon as practical and coordinate disclosure with the reporter.
